AWS Research

 1. Brief Overview

Amazon Web Services (AWS) is a public cloud computing service offered by Amazon. It provides a host of cloud services that businesses can leverage to develop, deploy, store and manage applications without having to rely on all its own physical assets.

 2. Global Infrastructure

AWS has a worldwide cloud infrastructure consisting of Regions and Availability Zones. Regions are regions of geographic space and Availability Zones are isolated locations within a Region. This infrastructure enables businesses to deploy applications as close to their users and enhance their availability and reliability.

 3. Cloud Management Console

AWS Management Console is a web-based console that provides access to and management of AWS services. The console allows users to create and configure resources and monitor services, manage security settings, and control their cloud infrastructure.

 4. Four Core Services

 Amazon EC2 - Amazon Elastic Compute Cloud (EC2) offers virtual servers that can be used to deploy applications and workloads in the cloud.

 Amazon S3 - Amazon Simple Storage Service (S3) is an object storage service that stores and retrieves objects like files, data, backups, and more.

 Amazon VPC - Amazon Virtual Private Cloud (VPC) enables you to isolate a virtual network that you can use with your AWS resources. It gives you control over networking, IP addresses, subnets and routing.

 AWS IAM - AWS Identity and Access Management (IAM) is used to control access to AWS resources. It allows administrators to manage users, roles, permissions, and security policies.

 5. Three Advantages

I.  Broad Services – AWS offers numerous services related to computing, storage, databases, networks, security, analytics, and more for the cloud.

II. Global infrastructure – AWS has a vast global infrastructure, enabling organisations to deploy applications in various geographical areas.

Scalability and flexibility – AWS resources can be scaled up or down as per the demand of the workload, supporting organisations to meet the changing demands.

 6. Common Enterprise Applications

Enterprises typically use AWS to host Web and mobile applications, store and back up data, run databases, handle disaster recovery, deploy enterprise applications, and conduct data analytics. Cloud solutions can be created by using multiple AWS services together to provide a scalable, highly available solution.
