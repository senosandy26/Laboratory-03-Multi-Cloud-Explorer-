# Checkpoint 4 – Cloud Platform Recommendation Challenge

 # Client A is a startup company.

Amazon Web Services (AWS) is recommended for use with this Cloud Platform.

AWS is recommended due to the flexibility and cost effective services it offers, which is ideal for startups with limited budgets. The pay-as-you-go pricing enables the company to start with a minimal infrastructure and scale up as the application expands. AWS also offers numerous managed services that can help minimize the need of a big technical staff. The start-up can leverage Amazon EC2, Amazon S3 and Amazon RDS to develop and run its mobile application.

Services:

 Amazon EC2 – Virtual servers for running application backends.
 Amazon's cloud storage for files and application data.Cloud storage for files and application data offered by Amazon.
 Amazon Relational Database Service (RDS) – Managed relational database service.



 # Client B – University

Recommended Cloud Platform: Microsoft Azure

The university already has Windows Server, Microsoft 365, and Active Directory, making Microsoft Azure the perfect selection. Azure integrates well with the existing Microsoft and its technologies, making migration and management of identity easier. Additionally, the university can utilize Microsoft Entra ID for managing identities and access to cloud services. The university can move some services at a time to Azure rather than all of its services at once.

Services:

 Azure Virtual Machines – Cloud based Windows Server workloads
 Microsoft Entra ID is the company's identity and access management solution.Microsoft Entra ID is the business's identity and access management solution.
 Azure SQL Database – Azure's cloud database service.



# Client C: AI Research Company

The recommended Cloud Platform is Google Cloud Platform (GCP).

This is due to the power of the infrastructure and specialized services offered by Google Cloud Platform for AI and Machine Learning workloads. The company can leverage high-performance GPUs and other accelerated computing devices for training and deployment of AI models. Google Cloud also offers managed AI and managed ML solutions to help make development and deployment easier. These services enable researchers to scale computing resources to meet the needs of their experiments.

Services:

 Google Compute Engine – Virtual Machines for high-performance computing that can be scaled up and down to meet demand.
 Google Kubernetes Engine (GKE) – Managed Kubernetes for AI/ML applications
 Collaborate with others to build and deploy AI and ML models with Vertex AI – Platform.Build and deploy AI and ML models with others on Vertex AI – Platform.



 # Client D: Global E-Commerce Company

Cloud Platform: Amazon Web Services (AWS) is recommended.

The recommendation for AWS is based on its large global infrastructure, which is optimized for highly available and scalable applications. The ecommerce firm can place applications in several areas and availability zones to boost dependability. Auto Scaling can easily adapt computing resources to customer needs, such as during periods of significant shopping activity and traffic rise. The company can rely on services like Amazon EC2, Amazon Elastic Load Balancing and Amazon DynamoDB to facilitate its operations in the worldwide market.

Services:

 Amazon EC2 provides scalable computing infrastructure.Amazon EC2 is a scalable computing infrastructure.
 ELB – distributes traffic to application resources
 Amazon DynamoDB is a highly scalable NoSQL database.
