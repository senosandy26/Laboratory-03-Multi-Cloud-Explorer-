# Checkpoint 8 – Mission Reflection

# 1.Which cloud platform impressed you the most? 
In this mission, I had the opportunity to gain more knowledge of cloud computing, Linux and the cloud giants AWS, Microsoft Azure and Google Cloud Platform (GCP). Of the three, AWS really made my head spin with the choice of the vast number of cloud solutions it offers, and the options for computing, storage, databases, networking, and security. I also discovered that AWS will handle both big and small projects and applications.

# 2.What similarities exist among AWS, Azure, and GCP? 
There are a number of similarities between AWS, Azure, and GCP. All three offer cloud computing services which enable users and organizations to access computing resources via the Internet. All provide virtual machines, storage, databases, networking, security services and tools to deploy applications. They also include support for Linux servers and scalable resources that enable enterprises to up or down resources as needed.

# 3.How do business requirements influence cloud platform selection? 
There's a strong influence on the platform you use: business requirements. The factors that a company would have to take into account are the budget, load, security, performance, scalability, and existing technology. An Azure-based platform may be preferable, for instance, for a company that already uses a lot of Microsoft products, or for a startup company that is looking for a platform based on cost and services available.

# 4.What did you learn from acting as a Cloud Solutions Consultant? 
The job of the **Cloud Solutions Consultant** was a reminder that it isn't just about picking the provider that's most popular. I must grasp the customer's needs before matching the needs to the right cloud services. This exercise enhanced my knowledge of comparing cloud platforms and giving sensible recommendations.

# 5.How has your GitHub Cloud Computing Portfolio improved after completing this mission?
Lastly, my portfolio on GitHub has been enriched with the results of my investigation, cloud platform comparisons, service mappings and reflections on my cloud computing portfolio. I also had a chance to get more comfortable with organizing files with Markdown and documenting my learning process on GitHub. This mission gave me a better appreciation of the concepts of cloud computing and how they can be used to meet real world business requirements.
